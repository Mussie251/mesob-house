# Mesob House

A modern Ethiopian & Eritrean restaurant web application built with React.

Mesob House is a portfolio project focused on creating a practical restaurant ordering experience while developing my skills in React, JavaScript, API integration, routing, state management, and responsive web development.

## Features

* Restaurant homepage with hero section and featured content
* Menu browsing
* Menu category filtering
* Individual dish detail pages
* Shopping cart
* Add and remove items from the cart
* Automatic cart total calculation in ETB
* Checkout form
* Responsive navigation and interface
* Menu data integration through a dedicated API service

## Tech Stack

* React
* JavaScript
* React Router
* Vite
* HTML
* CSS
* REST API integration
* Git & GitHub

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Mussie251/mesob-house.git
```

Navigate into the project:

```bash
cd mesob-house
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
